Network cameras (CCTV / DVR)

Your own cameras. Discovery scans the network this phone is on — connect to your home Wi-Fi first.
ARP-spoofs the camera↔router so its traffic passes through the phone, then reads the login from RTSP/HTTP Basic auth. Open the camera in your NVR/app while it runs. Digest auth isn't reversible.
Builds a time-range URL into the RTSP box above → then Snapshot / Record / Live pulls that span off the HDD. Channel = camera number; duration in minutes.
From far (away from home): use your DVR's DDNS host + forwarded RTSP port in the URL (rtsp://user:pass@myhome.ddns.net:554/…), or run a VPN back home (WireGuard/Tailscale) and use the LAN IP. Snapshot is built-in (bundled ffmpeg, no chroot); Live hands the URL to VLC/MX Player.
